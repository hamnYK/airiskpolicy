AI API 세팅

주간 TOP 10 관리자가 공유하는 서버 설정입니다. API 키는 Supabase Vault에 암호화해 보관하며 저장 후 원문을 다시 표시하지 않습니다. 빈 키 입력은 기존 제공자의 키를 유지합니다. 제공자를 바꾸면 새 키가 필요합니다.

설정과 모델 조회는 자료를 전송하지 않습니다. 아래의 AI 선정·내용 작성 버튼을 누르면 저장한 핵심 질문과 수집 후보의 제목·요약·날짜를 선택한 제공자에게 전송합니다. 제공자 API 사용 요금이 발생할 수 있습니다.

설정 확인 전

입력값은 브라우저 저장소·JSON 백업에 저장하지 않습니다. 저장 성공 시 입력란을 비웁니다.

API 키 발급 페이지 ▶

핵심 질문을 작성하고 초안 저장 후 실행하세요. 질문과 후보 자료를 설정한 AI 제공자에게 전송하며 API 비용이 발생할 수 있습니다. 수집 후보 안에서 질문과 관련된 건만 중요도 순으로 각 최대 10건 선정합니다. 1건 또는 0건도 가능합니다. 후보 요약은 최대 1,000자만 전달하며 웹 원문을 자동 검증하지 않습니다. 결과는 미리보기 후 초안에 반영하고 직접 검토·저장·발행합니다.

AI 선정 제안 · 검토 전

RISK 후보는 해당 주 AIM 최신 100건 표본을 관련 기사 수로 정렬합니다. POLICY 후보는 OECD 등록정보의 갱신일 기준이며 정책 발표·시행일이 아닙니다. 중요도 순위는 관리자가 원출처를 검토해 정합니다. 기사 수는 중복될 수 있으며 자동 요약은 사실 확인을 대체하지 않습니다.
