# Self-hosted typography

Downloaded 2026-09-15. Unmodified upstream WOFF2 files. Keep accompanying SIL Open Font License notices when distributing.

- SUITE-Variable.woff2: https://raw.githubusercontent.com/sun-typeface/SUITE/main/fonts/variable/woff2/SUITE-Variable.woff2
- SpaceGrotesk-Variable.woff2: https://raw.githubusercontent.com/floriankarsten/space-grotesk/master/fonts/woff2/SpaceGrotesk[wght].woff2
- PretendardVariable.woff2: https://raw.githubusercontent.com/orioncactus/pretendard/main/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2

SUITE: Korean headings, weight 700. Space Grotesk: English headings, weight 600–700. Pretendard: bilingual body and controls, weight 400–600. font-display: swap keeps content readable while fonts load.


UprightQuotes-Regular.woff2 / UprightQuotes-Bold.woff2: original rectangular punctuation glyphs generated by `2026.09.15/scripts/build-upright-quotes.py` (FontTools + Brotli). No upstream glyph outlines are copied or changed. Coverage: U+0022, U+0027, U+2018–201F, U+FF02, U+FF07. Smart quote code points retain their original text identity. CSS italic faces reuse upright outlines.

UprightQuotesMono-Regular.woff2 / UprightQuotesMono-Bold.woff2: original upright punctuation with a Consolas-compatible 1126/2048 em advance (two cells for fullwidth quotes). Used by code, pre, kbd and samp; italic faces remain upright.
